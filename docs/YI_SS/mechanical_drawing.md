# 机械制图及CAD基础

## 课程内容

- 课程学分：1.5
- 任课教师：费少梅
- 课程时间：大一 春
- 分数构成：平时40% + 期末60%
- 考试形式：闭卷考，记得带工具
- 课程大纲：暂无

## 个人经验

- 新书好用，还需要用到工程图学的书，学的内容其实不多，但是比较难也比较史，但资源也是非常有限
- 如果工图没有学的，不建议直接修机械制图，学了都可能听得云里雾里【忘记的太多】
- 会有CAD、SolidWorks上机实操课，去西4机房画图，挺折磨的，老师讲课/示范比较快，容易跟不上
- CAD和SW软件使用还是建议学一学，最后能提前自学一遍软件的基本操作，后面专业课还会用到
- 考试资料可以参考下面的[课程资源](#_3)，基本上就那几个知识点，改错方法也比较固定
