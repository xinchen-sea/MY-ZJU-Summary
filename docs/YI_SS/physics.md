# 大学物理 I

## 课程内容

- 课程学分：4（修的是甲，培养方案为乙）
- 任课教师：鲁定辉
- 课程时间：大一春夏
- 分数构成：平时（考勤、作业、4次小测）+期中+期末
- 考试形式：闭卷考
- 课程大纲：参考教材，力学+热学+电磁学前四节

## 个人经验

- 大物的课程应该是互通的，甲会比乙难一些，现在ydd出卷，相当于改革了，以前的经验反而不适用了，好像平时分数是赋分的，有点坑
- 大物乙考试卷子难度也变大了好像，基本上都建议面向ydd复习[ac01]
- 其他的我就不多讲了，建议平时也学一点，提前1-2周复习/补天，能力强的补两天也行，一定要多刷点题
- 依旧强烈推荐savia的讲义，特别是现在乙变难了，当甲学也没毛病
- ldh比较喜欢点名，一学期点了6-7次名吧，作业也挺多的，小测难度也大，不推荐
- 大物期中考和期末考基本上可以当做两门课学，考试范围重复较少，不懂怎么想的
