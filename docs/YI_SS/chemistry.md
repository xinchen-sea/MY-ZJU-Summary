# 工程化学

## 课程内容

- 课程学分：2
- 任课教师：陈卫祥
- 课程时间：大一 春
- 分数构成：平时30（有一次小测/期中考）+期末考70
- 考试形式：半开卷，允许带一张a4纸
- 课程大纲：参考教材/教学大纲

## 个人经验

- 高中选考化学的话，学工化还是很轻松的，只需要注意哪些名词/内容和以前学的不太一样就行，大部分都学过
- 考试能带A4纸，需要记忆/记不住的内容直接抄上去，简直不要太爽
- 没学过化学的可以认真阅读这个经验帖：[【学习天地】工程化学2023春学习经验分享](https://www.cc98.org/topic/5595371)
