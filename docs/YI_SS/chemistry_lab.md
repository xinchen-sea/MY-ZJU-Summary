# 工程化学实验

## 课程内容

- 课程学分：0.5
- 任课教师：方芳
- 课程时间：大一 春 双周
- 分数构成：4次实验、4份实验报告、出勤
- 考试形式：无考试
- 课程大纲：暂无，好像现在有本教材了

## 个人经验

- 4次实验都非常好玩，还能做肥皂，印刷画，金属老师人美心善
- 实验报告写起来有些烦，要写预习报告，纯手写，大部分都能抄又还好，就4份报告，忍忍呗
- 需要做一个实验安全考试，老师会发题库，花点时间看看，挺常识的，不难
- 实验只需要根据实验步骤完成就行，问题不大，报告打分基本在85-90
