# 大学英语 III

## 课程内容

- 课程学分：3
- 任课教师：李莎
- 课程时间：大一 秋冬
- 分数构成：很复杂
- 考试形式：闭卷考
- 课程大纲：参考教材

## 个人经验

- 大英其实大部分人都当水课上的，俺也一样，所以没什么建议可写
- 李莎老师是绝对的好老师，人美心善，甚至没有课后作业，也没有pre，舒服了
- 记得背单词，大英基本学不到什么新的内容，当四六级备考练习算了
- 期末考记得背单词，甚至背课文
