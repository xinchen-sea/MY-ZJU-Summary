# 线性代数

## 课程内容

- 课程学分：3.5
- 任课教师：董浙
- 课程时间：大一 秋冬
- 分数构成：平时作业+点名1次+小测3次+期末，好像现在有期中考了
- 考试形式：闭卷考
- 课程大纲：参考教材，好像有新书了

## 个人经验

- 线性代数甲的教学安排挺坑的，学起来也觉得不舒服，董老师自己也吐槽旧版教材编写顺序有问题
- 这是一门需要花一点功夫才能学好的课程，推荐看3b1b相关视频帮助理解线性代数的本质，但不是无脑吹捧3b1b
- 如果真的想完全学懂线代，推荐MIT Strang 老先生的公开课，但教学安排可能会有所差别，你需要自学跟上课堂进度才能拿到比较满意的平时分
- 公众号Randall爱数学，有线代习题答案【旧版】，但建议平时作业自己独立完成
- 补天建议先过一遍知识点/速通课，掌握基本知识后，面向历年卷复习【不补天也建议面向历年卷复习】
