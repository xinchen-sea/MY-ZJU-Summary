# 微积分（甲）I

## 课程内容

- 课程学分：5
- 任课教师：张泽银
- 课程时间：大一 秋冬
- 分数构成：平时（考勤、作业、小测）+期中+期末
- 考试形式：闭卷考
- 课程大纲：参考教材

## 个人经验

- zzy老师不点名，讲课口音听不懂，自学王者，坑的是作业很多，之前还选到一个不好的助教，习题课点名/小测更是神人……
- 微积分应该是大一甚至大学最重要的数理基础课，不要求完全掌握，起码要会计算吧，不然后面的课基本上都上不了
- 微积分I相对简单些，自学难度也不大，特别是前面几章，甚至是高中学过的
- 关注路老师的公众号，有习题解答也有历年卷，几乎不需要其他的资源，如果你需要笔记/讲义的话可以看看下面的【一份古早的讲义】，其实教材编写得也不差
- 个人经验是把历年卷弄懂一两套【题型都比较接近】，然后全刷一遍，考试就十拿九稳了，一定不要买教辅以为能帮助考试，编的还不如教材
- 平时也想努力的可以尽可能地弄懂习题，作业都独立完成，老师也会推荐使用吉米多维奇习题，真的很喜欢微积分（做题）可以买，千万别买来垫桌脚/盖泡面啊
- 补天的基础是先把课程学一遍，至少过一遍知识点，再通过做题强化，如果之前没听课/没学的建议先过一遍速通课
