# 理论力学（甲）

## 课程内容

- 课程学分：4
- 任课教师：陈丽华
- 课程时间：大二 秋冬
- 分数构成：平时40+期末60，当时clh老师班只有作业，有两次实验
- 考试形式：闭卷考，无小测，无期中
- 课程大纲：参考教材

## 个人经验

- 理论力学算是大二上比较重要的一门课，【后面的是废话】复变可能使用到的不多【专业课甚至最多考你拉氏变换】，而理论力学是材料力学的基础，材料力学算是我们专业的核心基础内容，也是考研的专业课科目
- 这门课也不太适合补天，比大物学的力学难一些，要理解、记忆的公式很多，补天的话会有些困难，【大物学得好的速成其实也不是不行】实在来不及就去b站搜速成课，有个14小时的质量还行
- 平时的话，我感觉clh老师讲得比较一般，我也不咋听，但是她经常点名又不得不去，在她教室里自己干自己的还会被说，挺烦的，但最后给分真的很好
- 静力学部分内容相对简单，自己看看书也能学会的那种；运动学、动力学部分自学起来有些费劲，教材编写得我不想评价，建议食用哈工大的公开课（b站或者mooc平台都可以）
- 实验的话非常简单，基本上去了听老师讲怎么操作就行，实验报告会发模板，记下数据什么的就行
- 考试只有5道大题，其中静力学、虚位移原理/达朗贝尔原理是送分题，可以优先解决，clh期末考改完卷还发了很长的总结，人还挺好呢
