# 工程热力学

## 课程内容

- 课程学分：2
- 任课教师：钱锦远/王秀瑜
- 课程时间：大二 冬
- 分数构成：平时+期末，占比未知，有一次小组作业（报告+汇报）
- 考试形式：闭卷，无小测，无期中
- 课程大纲：以老师PPT为主

## 个人经验

- 这门课挺神的，参考教材内容和上课内容有比较大的出入，王老师讲的前三章还乱七八糟的，钱老师讲的后四章比较有规律性，ppt也很舒服，所以我只做了前三章的笔记
- 前三章想认真学的，可以去看西交大的公开课，你会发现王老师的PPT是盗用的，讲课还没人家老师有逻辑性（乐）
- 过控特色，学得难考得简单，概念题（名词解释）、简单题，平时多用心，考试就觉得自己多小丑……
- 平时作业做不出来也没关系，能弄懂最好，弄不懂老师也不怪你，考试不考（乐），考场上发现计算题是一道高中物理热学题时，我差点笑出来
- 钱老师喜欢点名，当时还是两节早八，还安排在周五，挺难受的
