# 概率论与数理统计

## 课程内容

- 课程学分：2.5
- 任课教师：郑志浩
- 课程时间：大二 秋冬
- 分数构成：平时60%（作业、考勤、3次小测）+期末40%
- 考试形式：闭卷
- 课程大纲：参考教材

## 个人经验

- 之前概统小测是统一在网站/学在浙大上，经常雪崩，后来部分改课堂小测了
- 概统是最简单的数学课（确信），学起来简直不要太舒服（微积分学得不错的话），就好比高考概统的题都是送分的
- 有些久远了，好像也没啥想说的，建议面向历年卷复习，平时学习主要应对小测吧
- 更多的学习方法可以等我把讲义做出来，留个坑orz
- 还有就是，春夏概统比秋冬简单
