# 大学物理实验

## 课程内容

- 课程学分：1.5
- 任课教师：【挂名】肖婷
- 课程时间：大二 秋冬
- 分数构成：平时实验70% + 期末考试30%
- 考试形式：闭卷考
- 课程大纲：略，需要自己选课

## 个人经验

- 大物实验也是一大史课，要写预习报告、自己选课、写实验报告，当时还是纸质的，虽然可以打印，但还是比较麻烦的
- 绪论课爱听不听吧，但你要会数据处理，写实验报告的时候这是给分的一大重点，我基本都是用前人圣遗物，预习报告直接抄
- 选实验看运气，每次都卡死，没选上好的实验也是绝了，不推荐选光学实验、力学实验
- 我一般正式报告也会基本写好，到做实验的时候能直接填数据【这里圣遗物显得十分珍贵了】，顺便就算完了，这样做完实验，报告也差不多写好了，相当轻松
- 期末考不用花太多时间复习，在98上有很多的复习资料，选择性的使用一点，从历年题看，考的不算难
