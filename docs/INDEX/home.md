## 关于「本站」

不知不觉本科三年就过去了，总想留下点什么，身边很多人有自己的个人网站，或分享笔记，或分享课程心得，或记录学习/生活。
大一就已经接触到了类似hexo、mkdocs等博客框架，但一直没有维护好自己的小站，有些可惜。
~~为了“痛改前非”~~，想给过去留个小结，于是有了【课程总结】，也就是「本站」，或者说【补天建议】。
个体能力差异，不能保证我的方法对你也能达到同样的奇效，请不要把「本站」当做【通关秘籍】使用。
分数大概率和你的学习方式方法、花费时间精力相关，但分数不是一切，一个个数字代表不了什么。

「本站」编写于2026年7月底，搜集资料时间也限于2026年7月及以前，后续是否持续更新待定。
「本站」涉及的课程时间范围较大，部分课程和教材有所更改，可能缺乏一定时效性，
课程具体内容、平时分构成、**考试试卷题型（重点）**，还请自行了解求证其真实性。

那么，「本站」会有什么呢？

- [x] 笔者的课程经验
- [x] 笔者的课程资料（有的话基本都在置顶链接里）
- [x] 相关经验帖，笔者用过的资源
- [x] 回忆卷筛选、汇总(部分课程)

    「本站」内容均由笔者独立完成，个人时间精力有限，如有不妥之处，请读者批评指正。

    在这个AI泛滥的年代，不能保证「本站」没有一点AI生成的痕迹，但我会尽可能地保证「本站」的质量。
