# 后记

写到这里，「本站」基本上算是告一段落了。

从建文件夹到今天收尾，前后断断续续写了将近十天，正好赶上「了不起」的8月。难得放假得闲，正好把这三年欠的学业总结补上。三年不算很长，不过六个学期，几十个文件。

如果你认真翻完每一页，应该会发现我的行文风格/内容整理有些不太一致。有的课程写得热血沸腾，恨不得手把手教你补天；有的课程寥寥几句，带着「不想多说，自己体会」的敷衍。我按照记忆里由近及远的顺序写下我的课程总结，遥远的从前，多少有些模糊有些深刻的地方。有些课程资源确实已经冗余，我懒得整理，「通货膨胀」真不是我想看到的现象。但既然我已经动笔了，就应当对自己的内容、对可能的读者负责，我并没有任何敷衍的地方，通识课确实时间有限，我明天还有别的行程安排，已经来不及编写。至少，从头到尾，我都没有为了凑字数而硬写，全是自己键盘一字一句敲出来的。

写的过程中最大的感受是，这三年过得挺快，我咋上了这么多课程。从数理化机械基础，到力学几乎全家桶，再到专业课又硬又史，回头看都不知道自己怎么过来的。只记得，考试周一个晚上一个奇迹。但奇怪的是，写到最后反而有种不舍——终于，把这些年的挣扎和收获都安放了下来。似乎，我对自己的过去，更加坦然了一些。

关于过控这个专业，我在前言里已经讲了不少。这里不再重复，只想多说一句：不管你是主动选择的还是被动调剂来的，要么既来之则安之，要么努力转出去，去你想去的专业，见证它的荣辱兴衰。过控，它不是最好的专业，但也没那么差。你会在生产实习的时候吃席，会在某些老师的课上发现工科也可以很有趣，会在某一瞬突然发觉原来这个方向还挺有意思……这些都可能是你未来回想起来，觉得有点好笑又有点怀念的东西。正如AI所言，最大的收获可能不是知识本身，而是我有了一种「我确实在这里认真待过三年」的实感。

最后，感谢近年来分享经验的过控学子——不仅是因为有限的经验帮了我多少，而且这些都让我觉得有人在认真对待这件事，我也应该认真一点。感谢所有在 CC98 上分享过经验的前辈，你们是我写下去的原动力。也感谢看到这里的你。

大四还有课。可能还会有更新，也可能不会。

但至少现在，我可以暂时说一句：三年，写完啦。
