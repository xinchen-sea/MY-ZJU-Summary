# 电工电子学实验

## 课程内容

- 课程学分：1.5
- 任课教师：赵江萍
- 课程时间：大二 春夏
- 分数构成：线上作业（视频、自测题、考试）20%+期末仿真10%+实验报告10%+课堂操作10%+期末考40%
- 考试形式：最后一堂课课上闭卷考
- 课程大纲：略

## 个人经验

- 毫无疑问，史课，最史的实验课，而且是五级制……
- 实验操作课前听课了还是不难的，不会问一下边上同学也可以
- 记得做线上的作业，在「学银通」上，视频其实可以直接进度条滑到底，测试题好像有答案
- 实验报告占比不高，但是要求挺高，我基本上都是用98的实验报告复刻一个自己的版本，有点懒得抹掉个人信息，暂时不发
- 考试毫无头绪可言，把实验PPT内容都过一遍？考的也基本上都是PPT内容吧，简直是史，唯一优点是98上回忆卷特别多
