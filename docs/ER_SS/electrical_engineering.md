# 电工电子学

## 课程内容

- 课程学分：4.5
- 任课教师：孙晖
- 课程时间：大二 春夏
- 分数构成：平时10，spoc20，研讨课（思政报告）5，小测（3次）15，期末50
- 考试形式：闭卷考，斩杀线40
- 课程大纲：暂无，参考教材

## 个人经验

- 课程内容超级多，补天是极其痛苦的，**建议参考别人的学习经验**
- 这一学期的课其实我都没咋认真上，期末也没认真学，状态不怎么好，一个晚上速通了没挂
- 作业基本上有「电工电子学三件套」，问题不大，spoc章节测试也有答案，记得做
- 现在没有工材了，过控大二下期末就2门考试，应该算压力很小的，建议规划好复习时间，至少提前2-3周复习
- 实在没有办法，告诉你的补天邪修，花个1-2h速通一遍教材/PPT，了解大概内容之后，按章节把概念弄懂，
再把小部分计算弄懂，其实已经过斩杀线了；不满足的可以逐个知识点通关，把重点在纸上抄一遍，记得多少看个人能力；
还有时间的话，就可以开始刷历年题了，基本上都是用回忆卷吧（虽然很零碎），书店/打印店/学解的历年题狗都不用
