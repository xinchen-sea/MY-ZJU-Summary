# 过程工程流体力学

## 课程内容

- 课程学分：2
- 任课教师：赵永志
- 课程时间：大二 春
- 分数构成：作业30+考试70，共5次作业
- 考试形式：闭卷，无小测，无pre
- 课程大纲：参考教学PPT，共6章

## 个人经验

??? tips "一点小插曲"
    - 其实也没啥不能说的，第一次修这门课的时候挂了，期中考的时候正好处于~~失恋~~低谷期【其实现在也没想明白，只是不在意了】，根本无心复习，看了不知道有没有两个小时就去考试了
    - 大三修这门课的时候，因为是重修，作业就不用写了，平时课也没去上，甚至没进微信群，就期中考前复习了一天【？应该有吧】
    - 考试那天早八考数值计算方法，考完就去紫金港考了过工流，但感觉非常简单，无法理解去年怎么挂的，最后这两门都考挺好的，这里祝大家平安无事，考试顺利

- 赵老师人比较好，**平时不点名**，要求也不高，有可能他平时比较忙，然后这门课没有学在浙大也没有钉钉群，第一节课会来一个微信群
- 工流可能平时学起来比较难，公式比较多，作业的话部分简单，部分困难，基本上能对着PPT写出来，老师的PPT非常完美，甚至不需要做笔记
- 学得比较难，考试还是相对简单的，但是建议多花两个晚上学，概念多记一记，选择题和简单题可以参考历年卷，考的内容大差不差，当然也不可能完全一样
- 考试大题的话基本就是作业题或者作业题变式，甚至不考难度大的作业题，老师真的在尽力让你拿分了，作业的话98上有一份作业题答案，好好珍惜吧！
