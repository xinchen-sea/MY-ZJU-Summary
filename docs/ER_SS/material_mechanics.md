# 材料力学（乙）

## 课程内容

- 课程学分：4
- 任课教师：鲍荣浩/陶伟明
- 课程时间：大二 春夏
- 分数构成：平时（考勤、作业）40+期末60
- 考试形式：闭卷考，无小测（看老师的）
- 课程大纲：暂无

## 个人经验

- 这是一门非常多专业要修的课（机械、飞设、过控、车辆、农工……），98上资源也是非常多，鲍老师是绝对的好老师，其他的我不知道
- 这门课内容也是非常多，作业会比理论力学难一点？也还好，大部分作业能找到答案，教材也是更新到第7版了
- 考试内容记忆模糊了，一个晚上补天基本能学完，就是分数有点难看，老师给分挺好的
- 从学习内容上看，建议学习2-3个周，把历年题也刷一刷，其他建议可参考别人的学习路线
