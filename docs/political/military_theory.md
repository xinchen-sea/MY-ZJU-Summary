# 军事理论

## 课程内容

- 课程学分：2
- 任课教师：吕强
- 课程时间：（实际）大一 春夏
- 分数构成：平时60+期末40，平时包括考勤、讨论发言（算加分？）、论文
- 考试形式：开卷考，允许带任何纸质资料
- 课程大纲：参考教材，但是老师并没有按照课本讲

## 个人经验

- 吕强老师人很好，非常欢迎你和他讨论各种问题，考勤相对灵活，通常点名（5/6次）会开十分钟左右，没签上可以找他补签
- 论文要求较高，格式规范，时间相对宽松，但是注意提交时间和截止时间，及时提交，不然可能会扣分
- 喜欢军事的可以认真听讲，相信会有所收获，又不懂的也可以上课积极提问，老师都会耐心解答，不感兴趣的可以签完到回去睡觉，老师也不会点名提问
- 缺点可能是给分相对求是，slp/jmj听说好些（？）

## 课程资源

- 吕老师会发军事相关的复习资料、前人整理的提纲（课本目录详细版，98上也有）
- 课本、打印资料通常买二手书的时候会一起要吧，没啥其他的准备
- 个人觉得打印历年题进考场有点增加考试查阅压力，如果觉得合适也可以打印
