# 定向越野

## 课程内容

- 课程学分：1
- 任课教师：刘卫中
- 课程时间：大一 春夏
- 分数构成：考勤10+打卡15+理论考试10（已改为mooc）+身体素质（体测）25+专项40
- 考试形式：机房机考（改成线上mooc），专项考试有3次校园跑（玉泉、植物园、华家池）

## 个人经验

- 刘老师人很好，幽默风趣，上课之前喜欢讲很多内容，可能是故事，可能是奇奇怪怪的理论知识
- 比起其他体育课，定向越野整体强度较大，体力差的人可能不适应
- 平时跑步的话，跑校园挺随意的，刘老师也不管你的图纸打没打上，跑完丢掉就行（🤣）
- 考试去跑玉泉、植物园、华家池，还挺有意思的，就是累了点，大一想着锻炼一下体力来的，实际上现在体力也不咋样
