# 马克思主义基本原理

## 课程内容

- 课程学分：3
- 任课教师：严松
- 课程时间：（实际）大一 春夏
- 分数构成：平时60+期末40，平时：考勤、课堂发言（最少2次才给满）、1次小组展示、2/3次小测，读书报告（听说别的班有辩论）
- 考试形式：闭卷
- 课程大纲：参考教材

## 个人经验

- 思政课其实都差不多，卷平时分的话就积极参与课堂讨论和提问发言，小组成绩取决于小组质量（谁当组长谁冤种）
- 通常第一节课就要分组，展示主题不限，第二次课开始每周两个组展示，手气比较背抽中了第一组展示
- 严松老师一点也不松，很严，不是很推荐，但他一直说点名也没点过名（乐）
