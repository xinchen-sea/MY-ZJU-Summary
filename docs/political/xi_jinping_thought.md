# 习近平新时代中国特色社会主义思想概论

## 课程内容

- 课程学分：3
- 任课教师：苏冬/李梦宇
- 课程时间：大三 春夏
- 分数构成：平时60+期末40，平时包括考勤（点了2次名）、小组作业（2次主题展示、1次调研作业+汇报、小组发言）
- 考试形式：开卷考，允许带任何纸质资料
- 课程大纲：参考教材

## 个人经验

- 思政课其实都差不多，小组成绩取决于小组质量（谁当组长谁冤种），小组发言是硬性指标，卷不卷应该差不多，会影响你的平时成绩但不多
- 通常第一节课就要分组，小组展示由老师给出选题，每个主题由两个小组展示，调研项目不亚于一次社会实践，不推荐苏老师
- 虽然说继承了别人的n件套，但是真的用处不大，翻不过来
