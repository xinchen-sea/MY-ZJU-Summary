# 毛泽东思想和中国特色社会主义理论体系概论

## 课程内容

- 课程学分：3
- 任课教师：王晓梅
- 课程时间：大三 秋冬
- 分数构成：平时60+期末40，平时包括出勤、2次小组展示（一次读书/文献报告、一次调研报告【文物故事、微电影】）
- 考试形式：闭卷
- 课程大纲：参考教材，主要考1、2、6、7、8（不同老师说的版本不一样，呃）

## 个人经验

- 思政课其实都差不多，小组成绩取决于小组质量（谁当组长谁冤种），小组发言没有硬性要求，好像是个人加分
- 通常第一节课就要分组，读书报告由老师给出选题，调研内容不限
- 虽然说是毛概，但是内容包括了习思想之外的党的指导思想内容，而且23级考邓小平理论内容较多
- 王老师人挺好的，评价不错
- 闭卷考建议背书，或者找一份比较详细的资料背诵（其实就是背分点整理过的书），b站上有带背可以食用，个人体验可能有所差异
