# 中国近现代史纲要

## 课程内容

- 课程学分：3
- 任课教师：叶君剑
- 课程时间：大一 秋冬，好像24级开始改预置春夏了
- 分数构成：平时70+期末30，平时包括考勤、小组展示（鼓励创新形式）、读书报告、口述历史（也可能是论文）
- 考试形式：开卷考，只允许带课本，不能夹/带笔记
- 课程大纲：参考教材，中国近现代史相关，主要是近代、近现代

## 个人经验

- 思政课其实都差不多，卷平时分的话就积极参与课堂讨论和提问发言，小组成绩取决于小组质量（谁当组长谁冤种）
- 通常第一节课就要分组，小组展示主题只要跟近现代史相关就行，由其他小组打分
- 读书报告、口述历史都是个人作业，格式规范，内容不差的话基本给分都差不多
- 复习建议给不了一点，感觉选择题考得比较细，如果有精力可以过一遍书，但正常都不会花太多时间复习吧
