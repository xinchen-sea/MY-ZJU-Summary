# 篮球（中级）

## 课程内容

- 课程学分：1
- 任课教师：金慧娟
- 课程时间：大二 春夏
- 分数构成：考勤10+身体素质25（体测）+体育打卡15+MOOC（含考试）10+专项技能40
- 考试形式：线上MOOC期末考，开卷；专项线下考试

## 个人经验

- 好课，金老师人也很好，喜欢篮球的非常推荐
- 中级班比初级班会难一点，但是有篮球基础的其实影响不大
- MOOC可以用刷课脚本，但智慧树网页更新之后好像不会自动播放下一视频了，脚本可能实用性不强了
- 线上考试的话，98上有题库分享，大部分能找到
- 专项考试分两项，一项是1分钟定点投篮，4个及格8个满分；另一项是运球
