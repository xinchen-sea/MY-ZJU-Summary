# 生产实习（~~食席~~

从去年开始，生产实习变成旅游了。回来之后，宿舍真的没有酒店住的舒服……

## 课程内容

- 课程学分：3
- 任课教师：两位班主任（马凯/陈传勇）
- 课程时间：大三短学期，今年是7.7-7.18（7.5动员，7.6凌晨出发，7.18早上考试，中午出发回杭州）
- 分数构成：考勤表现（10%）+ 实习记录本（30%）+ 电子实习报告（20%）+ 考试（40%）
- 考试形式：开卷，只能带实习记录本，但是老师不收手机

## 个人经验

- 从实习安排来看，主要去的两家公司，科新机电和东方电气（及其子公司），中间参观了两弹城、利尔化学（老总真的豪爽）、东汽汉旺地震遗址、紫坪铺水电站等，其实说去旅游也不为过，美其名曰生产实习/游学，还不用出一分钱，其他人不知道，反正我是玩爽了
- 实习记录本的话，一开始到科新还记录了一点东西，后面讲座越听越困，拍了PPT也懒得抄，再到后面，我直接豆包了，但其实就内容而言，考试也没啥好考的，无非就是压力容器和流体机械，老师说的考试范围也是这个（如说），另外在东方汽轮机、东方锅炉，强调了什么数字化，可能会考一点吧，马凯说过控也要迎来第二次变革（~~AI智能化~~）
- 东方电气的讲座质量真的差吧，一直在宣传什么企业文化，主讲人都是人力资源部或者企业文化部之类的，这央企不得不品，但比起科新的猪食（还要洗盘子），东方的食堂真的好吃
- 考勤上，原则上不允许外出，每天让小组长走个形式的清点人数，实际上没有老师亲自来查寝，~~说不准老师自己也出去玩了，我们一起来旅游的~~，另外，林林总总吃了几次席，味道上勉强说得过去，本广东人唯一接受不了的就是四川火锅的辣锅，后面有机会再写一个旅游攻略

??? tip "实习报告/记录本"

    === "实习报告"
        - 先上传实习时间及安排
        - prompt：请根据实习时间及安排，结合实习期间的所见所闻，撰写一篇不少于2000字的实习报告，内容包括实习总结和感悟，以及对实习的建议等，虽然没有格式的要求，但请写的规范、有水平一点。
        - 有一个民间降AIGC的skill，自己搜一下，或者让AI给你写成一整篇文章，不要分章节
        
    === "实习记录本"
        - 分开上传每次实习的具体内容
        - prompt：请根据实习时间及安排，结合实习期间的所见所闻，撰写实习记录，只需要记录一些内容要点
